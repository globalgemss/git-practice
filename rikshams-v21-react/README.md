# RikshaMS V26.1.12 — Modern Modal & Form System Final

React + Vite + Supabase transport and labour management application.

This build keeps the V26.1.11 order/payment journey and V26.1.10 dispatch assignment workflow, while upgrading the complete modal/form design system for consistent desktop, tablet and mobile use.

## Run
```bash
npm install
npm run dev
```

## Production validation
```bash
npm run build
```

No additional Supabase SQL is required for this UI release.
